# Карточка задачи

## Карточка задачи

- Идентификатор: `BUG-009`
- Родительская задача: `FEATURE-002`
- Заголовок: `Кнопки добавления меню должны показывать названия`
- Единица поставки: `FEATURE-002`
- Роль: `Фронтенд`
- Контурная карта: `docs/architecture/application-map/frontend-backoffice.md`
- Приоритет: `Высокий`
- Статус: `Готова к работе`

## Цель

`Исправить воспроизводимое frontend-расхождение вкладки Меню: кнопки Добавить группу и Добавить товар должны показывать читаемые названия в панели действий.`

## Детали дефекта

- Контур причины: `frontend`.
- Затронутые сценарии: `FTS-002-001`, `FTS-002-002`, `FTS-002-005`, `FTS-002-010`.
- Шаги воспроизведения:
  1. Открыть вкладку `Меню`.
  2. Проверить панель действий под заголовком экрана.
  3. Сравнить кнопки `Добавить группу` и `Добавить товар` с `.references/Expressa_admin/src/app/screens/MenuScreen.tsx`.
  4. Проверить пустое состояние меню, где `Добавить товар` может быть disabled.
- Фактический результат: кнопки добавления отображаются как primary/outlined области без читаемых названий.
- Ожидаемый результат: кнопка `Добавить группу` показывает читаемое название в primary-состоянии; кнопка `Добавить товар` показывает читаемое название в enabled и disabled состояниях; tooltip `Сначала создайте группу` сохраняется для disabled-сценария.

## Границы задачи

### Функциональные требования

- Система должна отображать название `Добавить группу` на первой кнопке панели действий вкладки `Меню`.
- Система должна отображать название `Добавить товар` на второй кнопке панели действий вкладки `Меню`.
- Система должна сохранять читаемость названий кнопок на desktop и mobile viewport.
- Система должна сохранять disabled-состояние `Добавить товар`, когда в каталоге нет групп.
- Система должна сохранять открытие диалога создания группы через `Добавить группу`.
- Система должна сохранять открытие диалога создания товара через `Добавить товар`, когда действие доступно.

### Scope Constraints

- Задача охватывает только клиентскую реализацию панели действий вкладки `Меню`.
- Задача охватывает общий `ui-button` только в части, необходимой для восстановления читаемости текста.
- Задача охватывает визуальное соответствие кнопок текущему UI-контракту.

### Safety Constraints

- Система должна сохранять route `/menu` и administrator-only guard.
- Система должна сохранять текущий contract boundary `/backoffice/menu/*`.
- Система должна сохранять validation и error mapping каталога меню.
- Система должна сохранять canonical flow создания группы опций через `Добавить группу` и флаг `Группа опций`.
