# Orchestration prompts

## Назначение

`process/prompts/orchestration/` содержит процессные промпты для queue-driven агентной работы.

Queue-driven режим означает, что текущее состояние работы хранится в файлах репозитория, а главный агент только диспетчеризует очередь подзадач через прямых субагентов.

## Состав

- `main-orchestrator.md` — главный оркестратор очереди: создает рабочую папку, запускает однотипных `Universal Worker`-субагентов, читает только краткие результаты и поддерживает состояние очереди.
- `universal-worker.md` — единый worker-промпт: субагент сам берет следующий atomic step из `execution-plan.md`, читает свой контекстный пакет, выполняет ровно один шаг и пишет краткий результат.
- `sub-orchestrator.md` — compatibility-shim для старых запускных промптов; не является рабочей ролью.

## Каноническая рабочая папка

Для большой задачи используется:

```text
.agent-work/<TASK-ID>/
|-- execution-plan.md
|-- orchestration-checkpoint.md
|-- context-<SUBTASK-ID>.md
`-- worker-results/
    `-- <timestamp>-<SUBTASK-ID>.md
```

## Основные правила

- Главный оркестратор не выполняет production-работу, QA, BUG-fix, проверки и широкий анализ.
- Главный оркестратор запускает прямых субагентов с одним и тем же worker-промптом.
- Субагент выполняет ровно один atomic step за запуск.
- Субагент берет состояние из файлов, а не из памяти главного агента.
- Все разрешимые blocker'ы превращаются в resolver-подзадачи в `execution-plan.md`.
- Hard blocker останавливает workflow только после audit классификации: отсутствие QA precondition, test user, seed, fixture, context package, child task или BUG с ясным контуром причины сначала превращается в resolver-подзадачу; человеком блокируются только продуктовые решения, внешние секреты/доступы, внешний стенд, approved UI source или изменение scope.

## Когда использовать

Использовать для больших задач, которые требуют несколько проверяемых подзадач, несколько зон правок, разные виды проверок или широкий read set.

Для маленькой задачи с одной зоной правок orchestration не нужен.
